## 2. 当前完整调用链（v1 legacy）

```
web POST /api/dual_engine/start_task
  → dual.start_creation_task(async)
    → run_creation_pipeline
      Step1: collect_inputs()
            → glm_market_insight (GLM)
            → _codex_hypothesis_books (本地规则+DSL 拼装，非外部 Codex API)
            → glm_audit_hypotheses (GLM)
      Step2: run_internal_packs
            → validate_strategy + _backtest
            → anti_overfit (WF folds)
            → extreme_friction (slip×2 / latency / fill_fail)
            → logic_destruction: 参数 ±20% 扰动，mean_net>-0.01 即 pass  ←【制度要删除的规则】
            → glm_internal_gate
      Step3: glm_sim_review（GLM 模拟 DS/Qwen 胜率 ≥55%）
            → _apply_repair_operator（收紧 RSI / 加 CCI / 缩短持仓，最多 4 轮）←【无根因、可引入未批准过滤器】
      Step4: formal_ds_qwen_review（DeepSeek+Qwen 理论胜率 ≥50%）
            → human_confirm_pipeline.ingest_and_screen
旁路: --evolve / qiyu-dual-engine-evolve.timer → evolve_once（遗传池）
```

关键缺口对照制度要求：

- 无结构化 `mechanism_statement` 必填校验
- Codex 权限无硬约束；修复可自行加 CCI/RSI
- 无 `condition_audit` / 机制忠诚度持久化
- `logic_destruction` = 参数±20%恶化判定（与新 A/B/C 测试冲突）
- 无机制漂移检测；失败归档多为自由文本/stage 字符串
- 正式复核以理论胜率为主，非四维攻击面
- 无探索模式 A/B/C/D 与 Mode A 数据隔离
- 无 `mechanism_fingerprint` 去重索引
- OpenAI 槽位已映射 GLM，不能伪造独立 OpenAI 复核
- 第四栏仅洞察/状态机/进化池/正式提交，无机制声明/指纹/审计/四维报告
